# BM STUDIO — дизайн интерьера

Одностраничная сайт-визитка дизайнера интерьера.

**Сайт:** https://malikovnamakpal.github.io/vizitka/

## Что на странице

- Логотип BM STUDIO — каждые 3 секунды плавно поворачивается вокруг своей оси
- Название студии и подпись «Дизайн интерьера»
- Кнопка «Написать мне» — открывает чат в WhatsApp
- Фоновое фото интерьера в тёплой гамме

## Файлы

- `index.html` — сама страница
- `images/logo.png` — логотип
- `images/background.jpg` — фоновое фото

## Как открыть

Перейдите по ссылке выше или скачайте проект и откройте `index.html` двойным щелчком.

## Технологии

HTML + CSS, без сборки и зависимостей. Шрифты — Cormorant Garamond и Montserrat (Google Fonts).
