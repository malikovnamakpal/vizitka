# Макпал — дизайнер интерьера

Одностраничная сайт-визитка дизайнера интерьера.

## Что на странице

- Логотип: тонкий контур дома с сердцем внутри
- Имя и профессия
- Кнопка «Написать мне» — открывает чат в WhatsApp
- Фон в тёплой гамме: коричневая стена, светлая штора, столик с лампой и бархатные кресла

## Как открыть

Скачайте файл `index.html` и откройте его двойным щелчком — страница откроется в браузере.

## Технологии

Один файл HTML + CSS, рисунки сделаны на SVG. Шрифты — Cormorant Garamond и Montserrat (Google Fonts). Без сборки и зависимостей.
